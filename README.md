# Inteligencia Artificial, Herramientas y Futuro del Trabajo

Curso teórico-práctico de nueve clases para jóvenes de 18 años en adelante. Propone un recorrido desde los conceptos fundamentales de inteligencia artificial hasta el diseño y la evaluación de soluciones con IA.

**Duración:** 9 clases de 120 minutos · 18 horas  
**Recorrido:** Comprender → Usar → Conectar → Diseñar → Presentar

## Objetivo

Comprender cómo funciona la inteligencia artificial actual y aprender a utilizarla para estudiar, crear, investigar y resolver tareas. El curso combina experimentación práctica con revisión crítica, supervisión humana y uso responsable de las herramientas.

## Temario

| Clase | Tema |
|---|---|
| 1 | Descubro la IA |

| 4 | La utilizo para crear | 
| 5 | Le enseño procedimientos | 
| 6 | La conecto con herramientas |
| 7 | Diseño agentes y flujos | 
| 8 | Construyo una solución | 
| 9 | La presento y evalúo | 

## Metodología

Cada clase combina conceptos y ejemplos, una demostración docente, trabajo grupal, puesta en común y cierre. Las actividades proponen resolver situaciones concretas, comparar resultados y explicar las decisiones tomadas.

La IA se aborda como una herramienta de trabajo: sus resultados requieren revisión y no se consideran correctos solo por estar bien redactados. Se promueve el cuidado de los datos personales y confidenciales, y el uso de ejemplos ficticios o públicos en las demostraciones.
